# Содержание репозитория 
Данный репоиторий представляет собой полнофункциональный прототип 2D action игры с элементами rpg под названием Elementals.

---
# Запуск игры
1. Скачать .zip архив
2. Разархивировать
3. Запустить файл Elemental.exe

---
# Ссылка на репозиторий с текстом программы
Билд игры находится по ссылке: https://github.com/Owowound/HSE_Coursework

# Структура
```plaintext
- D3D12
  Папка, связанная с Direct3D 12. содержит данные необходимые для работы графического процессора.
- Elemental_BurstDebugInformation_DoNotShip
  Папка содержит отладочную информацию.
- Elemental_Data
  Папка содержит все ресурсы игры.
- MonoBleedingEdge
  Папка содержит файлы, необходимые для работы скриптов игры.
- Elemental.exe
  Исполняемый файл, ззапускающий игру.
- UnityCrashHandler64.exe
  Файл для обработки сбоев игры.
- UnityPlayer.dll
  Библиотека, используемая Unity для выполнения игры.
